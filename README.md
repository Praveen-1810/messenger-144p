# 144P – Low Resolution. High Connection.

144P is a Java-based desktop messaging application built to make communication simple and convenient.

## Features

- User registration and login
- Group chat rooms
- Direct messaging
- Code sharing
- Message history using SQLite
- Unread message notifications
- Local network server discovery

## Technologies Used

- **Language:** Java
- **GUI:** Java Swing
- **Networking:** TCP and UDP Socket Programming
- **Database:** SQLite
- **Database Connectivity:** JDBC
- **Concepts:** OOP, Multithreading, Synchronization

## Project Structure

- `Client.java` – Desktop client application and user interface
- `Server.java` – Chat server
- `ClientHandler.java` – Handles individual client connections
- `Database.java` – Database initialization and management
- `UserService.java` – User registration and authentication
- `RoomManager.java` – Group chat room management

## Getting Started

### Requirements

- Java Development Kit (JDK)
- SQLite JDBC driver

### Running the Application

1. Clone the repository:

   ```bash
   git clone https://github.com/Praveen-1810/144P.git
   ```

2. Open the project folder.
3. Compile the Java files with the SQLite JDBC driver in the classpath.
4. Start the server.
5. Run the client application.
